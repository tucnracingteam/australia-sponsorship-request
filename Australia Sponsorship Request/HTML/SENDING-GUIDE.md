# Test the Australia sponsorship email

The campaign page is hosted at:

`https://tucnracingteam.github.io/australia-sponsorship-request/`

The root `index.html` is the campaign design. To test it in Thunderbird, open the published page in a browser, select and copy the rendered page, then paste it into an HTML-composed message. Send the first test to yourself and review it in Gmail on desktop and mobile before contacting sponsors. Browser-to-email pasting can change layout details because email apps support a narrower set of HTML and CSS than browsers.

`index-email.html` is included as an email-oriented reference; the campaign's public page remains the root `index.html`.
